# Star Wars – Unity Port

This folder is the Unity/C# migration package for the uploaded Pygame project.

The gameplay goal is to keep the existing 2D arcade rules while replacing Pygame runtime primitives with Unity scenes, GameObjects, SpriteRenderers, Collider2D, Time and the Input System.

See:

- `MIGRATION_PLAN.md` – architecture and migration order
- `PORT_FILE_MAP.md` – every Python file and its Unity target
- `UNITY_SETUP.md` – Unity project/prefab/scene setup
- `Assets/Scripts/` – C# port
